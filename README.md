# pandaismyname1.github.io

Personal site for Emanuel Păiuș, served by GitHub Pages from the `main` branch.

Plain HTML, CSS and a few lines of JavaScript. No build step. Fonts are Geist and Geist Mono (SIL OFL), self-hosted from `assets/fonts`. Icons are from Phosphor (MIT), inlined as an SVG sprite.

To preview locally:

```bash
python3 -m http.server 8765
```

then open http://localhost:8765.
